A simple Band Name Generator web app built with Node.js and Express.js.  
Generates a fun band name based on user input submitted through an HTML form.

### Tech Stack
- Node.js and Express.js for server-side logic and routing  
- HTML and JavaScript for the frontend UI  
- Body-Parser and Morgan middleware for parsing requests and logging HTTP traffic  
- Postman used for testing routes.
  
### Features
- Takes user input (e.g., Name, pet name, or any keywords) and returns a generated band name  
- Demonstrates basic Express routing, middleware usage, and form handling in Node.js  
- Simple structure suitable for beginners exploring full-stack JavaScript
